# 🐾 소환수 키워서 살아남기 (Summoner Survivors)

고대 신수 육성 & 4인 가족 협동 웹 서바이벌 게임!
아빠와 아이들이 함께 모바일/PC 웹 브라우저에서 실시간으로 즐길 수 있습니다.

## 🎮 게임 특징
- **소환수 전투 스타일 분기**: 각 소환수마다 [⚔️ 근거리 전투] vs [🏹 원거리 포격] 2개 스타일 선택 가능
- **3단계 전직 계보**: 1차 기본 -> Lv.15 2차 전직 -> Lv.35 3차 최종 각성 신수 강림
- **11대 합성 진화 레시피**: 만렙(Lv.8) 주스킬 + 시너지 패시브 조합으로 초강력 궁극기 해금
- **4인 가족 협동 멀티플레이**: WebRTC P2P 기반 4자리 방 코드로 스마트폰/PC 동시 접속
- **AI 가상 동료 지원**: 혼자서도 2~4인 파티 플레이 가능
- **모바일 완벽 지원**: 좌측 가상 조이스틱 터치패드 & 우측 원터치 궁극기 버튼

## 🕹️ 조작법
- **PC**: `W/A/S/D` 또는 `방향키` (이동), `Space` / `마우스 클릭` (필살기 시전)
- **모바일**: 좌측 가상 패드 터치 드래그, 우측 `💥 READY!` 필살기 터치

## 🚀 기술 스택
- HTML5 Canvas, Web Audio API, PeerJS (WebRTC P2P)
